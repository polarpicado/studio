# Joao Basanta | Web Portfolio

🚀 Web profesional pensada para presentar con claridad experiencia en automatizacion, IA aplicada, integracion de sistemas y soporte TI.

La idea no fue construir solo un portafolio tradicional, sino una web que funcione como una pieza comercial y tecnica al mismo tiempo: un espacio para mostrar resultados, demos funcionales, proyectos reales y una propuesta de valor clara para reclutadores, lideres tecnicos y equipos de operaciones.

## 🌐 Sitio publicado

Disponible en:

[https://jbasanta.vercel.app/](https://jbasanta.vercel.app/)

## ✨ Que comunica esta web

Esta experiencia esta construida para que, en pocos segundos, se entienda un enfoque claro:

- automatizacion de procesos con IA y sistemas integrados
- conexion entre chat, datos, tickets y flujos operativos
- trabajo con impacto medible en soporte y operaciones TI
- capacidad de mostrar demos reales, no solo descripciones

La home actual incluye:

- hero principal con mensaje directo
- metricas de impacto
- seccion destacada con demos funcionales
- proyectos clave
- habilidades organizadas por capacidades
- certificaciones
- formulario de contacto y acceso por WhatsApp
- asistente integrado del portafolio

## 🎯 Enfoque del producto

La web esta diseñada alrededor de una narrativa concreta:

**automatizacion + IA + ejecucion real**

Por eso prioriza:

- claridad de posicionamiento
- presentacion visual moderna
- evidencia de implementacion
- demos clicables
- contacto rapido

## 🤖 Construida con inteligencia artificial

El proyecto fue desarrollado con apoyo intensivo de inteligencia artificial en distintas capas del proceso:

- ideacion de estructura y narrativa
- redaccion y refinamiento de contenido
- generacion y ajuste de componentes
- apoyo en integracion tecnica
- iteraciones visuales y mejoras UX
- creacion de recursos graficos para proyectos

La IA fue una herramienta de aceleracion y co-creacion, pero la direccion del proyecto responde a una intencion clara: presentar una propuesta profesional solida, moderna y demostrable.

## 🛠️ Desarrollo local

### Requisitos

- Node.js 18 o superior
- npm

### Instalacion

```bash
npm install
```

### Levantar entorno local

```bash
npm run dev
```

La web queda disponible en:

[http://localhost:3000](http://localhost:3000)

## 📜 Scripts utiles

```bash
npm run dev
npm run build
npm run start
npm run typecheck
```
