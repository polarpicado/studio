# **App Name**: Basanta Portfolio

## Core Features:

- About Me Section: Display a professional summary, highlighting Joao Basanta's experience and expertise in system engineering and automation.
- Project Gallery: Showcase Joao's projects with detailed descriptions of his contributions and the technologies used.
- Skills List: Present a clear list of Joao's key skills, emphasizing his proficiency in Python, n8n, and Cloud solutions.
- Certification List: A list of certificaciones availibles.
- Contact Form: Provide a form for potential employers or collaborators to directly contact Joao.
- IA Portfolio Assistant: Implement Gemini-powered tool to answer user questions about his work experience and capabilities, to provide more in-depth information. This is in place of lengthy, manual email conversations about this capabilities.
- SEO Meta-Data Implementation: Integrate provided SEO title and description meta-data for enhanced search engine visibility.

## Style Guidelines:

- Background color: Light gray (#F0F4F8) to provide a clean and modern backdrop.
- Primary color: Muted blue (#64B5F6) to evoke a sense of trust and professionalism.
- Accent color: Subtle tech green (#A5D6A7) for highlighting key elements and calls to action.
- Body and headline font: 'Inter', a grotesque sans-serif, for a modern, neutral and readable feel.
- Use a consistent set of icons (i.e. Font Awesome) to visually represent skills and project categories.
- Maintain a clean, minimalist layout with ample white space for readability and visual appeal.
- Implement subtle animations (e.g., fade-ins, transitions) to enhance user experience without being distracting.
